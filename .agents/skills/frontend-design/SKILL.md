# Frontend Design

Create distinctive, polished, and high-performance web frontends and portfolio sites.

## Core Design Principles

1. **Memorable Hero & First Impression**: Make the hero section stand out with strong display typography, distinctive visuals, or interactive elements.
2. **Bespoke Typography**: Choose expressive typefaces tailored to the identity of the brand/portfolio. Set intentional line-heights, letter-spacing, and font-weights.
3. **Harmonious Color Palette**: Use curated hex/HSL color scales with deliberate contrast ratios. Avoid plain black (#000) or generic gray/blue.
4. **Restrained Motion & Interactions**: Add micro-interactions, smooth hover states, and staggered reveals that feel intentional rather than chaotic.
5. **Legible & Active Copy**: Write concise, direct labels and CTA buttons in sentence case.
